# Loan EMI Calculator

A full-stack Loan EMI Calculator web application built with Django and PostgreSQL.

## Features

- User Registration & Login
- EMI Calculator
- Amortization Schedule
- Loan Comparison
- Loan Eligibility Calculator
- Prepayment Calculator
- Dashboard with Charts
- Loan History
- Export to PDF
- Export to Excel
- REST API with Django REST Framework
- JWT Authentication
- PostgreSQL Database

## Tech Stack

- Python
- Django
- PostgreSQL
- HTML
- CSS
- Bootstrap
- JavaScript
- Chart.js
- Django REST Framework
